Como usar um túnel existente

Se ele encaminha uma porta local para o SSH do servidor, use localhost, a porta local e seu usuário remoto. Um túnel para uma página web não oferece acesso SSH.

Para uma conexão master aberta com ssh -S, informe o mesmo alias e o caminho do socket. Execute este painel no mesmo ambiente Linux/WSL da conexão. A autenticação usa suas chaves, agente ou conexão compartilhada; resolva senhas e confirmação de identidade antes no terminal.
