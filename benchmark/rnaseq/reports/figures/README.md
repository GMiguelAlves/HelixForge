# Stage 9B.1 figures

Figures in this directory are rendered on the institutional Slurm cluster from
the frozen Stage 9B.1 evidence. PNG files are embedded in the benchmark report;
matching PDFs are retained for publication-quality reuse. The machine-readable
manifest records file checksums and the immutable benchmark subject.

The final render passed in Slurm job `15624` with R 4.3.3 and Python 3.12.4.
The set contains:

1. gene abundance recovery;
2. transcript quantification summary;
3. log2 fold-change recovery;
4. precision-recall performance;
5. semantic reproducibility endpoints;
6. execution performance and scheduler wait.

The coverage-depth figure belongs to a later benchmark arm and was not created
for Stage 9B.1.
