# Figuras da Etapa 9B.1

Este diretório contém as seis figuras científicas produzidas a partir das
evidências retidas da validação sintética de RNA-seq. Os arquivos PNG são
referenciados no relatório e os PDFs equivalentes foram preservados para uso
em publicação. O manifesto registra os checksums e identifica a tag e o commit
imutáveis avaliados. A renderização final foi executada no Slurm pelo job
`15624`, com R 4.3.3 e Python 3.12.4.

A série de profundidade de cobertura não foi executada nesta etapa e, por isso,
nenhuma figura desse braço foi produzida.
