# Synthetic narrow compact results

This directory contains compact, version-controlled evidence from the frozen
synthetic narrow-peak benchmark. Raw FASTQs, BAMs, indexes, Nextflow work files
and other large intermediates are intentionally excluded.

- `technical/`: selected artifact checksums, FRiP and completion checks;
- `metrics/`: ground-truth, signal-class and replicate metrics;
- `figures/`: PNG/PDF figures and their checksum manifest;
- `performance/`: descriptive Nextflow, Slurm and storage measurements.

See [`synthetic_narrow_benchmark.md`](../../reports/synthetic_narrow_benchmark.md)
for the interpretation and classification.
