# Synthetic broad benchmark results

This directory contains the compact, reviewable evidence retained in Git for
the frozen synthetic broad-domain ChIP-seq benchmark. Large FASTQ, BAM,
BigWig, work-directory and raw coverage artifacts are retained only in the
verified audit archive described in the benchmark report.

- `technical/`: selected outputs and execution checks.
- `metrics/`: ground-truth, topology, repeat-overlap and coverage metrics.
- `figures/`: rendered scientific figures and their manifest.
- `performance/`: descriptive Nextflow and Slurm resource accounting.

See [`synthetic_broad_benchmark.md`](../../reports/synthetic_broad_benchmark.md)
for the frozen interpretation and arm classification.
