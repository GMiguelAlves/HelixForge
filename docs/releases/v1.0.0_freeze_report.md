## Scope and immutability

This is an administrative release freeze. The validated RNA-seq, ChIP-seq,
and Integrative scientific implementations are unchanged. No workflow
algorithm, provider logic, statistical method, manifest schema, scientific
default, Candidate Score definition, or benchmark threshold was modified.

The clean release branch was created from remote `master` commit
`8a1eac201d34861a9f8d3cd595b472a5ca76cc97`. The final release commit is the
commit resolved by the annotated `v1.0.0` tag; this avoids embedding a
self-referential commit identifier in the commit itself.

## Known limitations

- Salmon numerical nondeterminism under some threading conditions.
- Synthetic broad-domain fragmentation behavior.
- RN3 not evaluable under the frozen null-model requirements.
- Strong replicate asymmetry in the real broad ChIP-seq dataset.
- Integrative IB4 expected-range limitation.
- Integrative IB5 not evaluable under the current directional Fisher contract.
- Complete-workflow cache persistence remains environment-dependent in the
  tested HPC setup.
- Apptainer/Singularity, Conda, STAR, and single-end RNA-seq remain outside the
  certified v1 production matrix.

These are scope, runtime, dataset, or methods limitations. None demonstrates a
central scientific implementation failure in the frozen v1 paths.

- Required scientific paths and terminal contracts are present.

- The overall decision remains `PASS_WITH_LIMITATIONS`; it is not promoted to
